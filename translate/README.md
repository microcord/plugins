# Translate

Port of [Tyman's Translate plugin for Aliucord](https://github.com/TymanWasTaken/aliucord-plugins/tree/main/Translate).

- Long-press a message: **Translate Message** replaces its text with the translation; **Show Original**
  switches back.
- `/translate text [to] [from] [send]` translates text and sends it, or with `send: false` only shows it.
- Settings: the language messages are translated into.

Uses Google Translate's free endpoint, which is rate limited.
